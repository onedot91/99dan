# 완성된 세로식의 빈칸 문항 검증

2026-10-03. 요청 범위: 中·上 10문제에 계산이 끝난 식의 일부 빈칸을 채우는 문항 추가. 로컬 검증 후 사용자 승인으로 운영 반영을 완료했다.

## 구현

- 中: 10문제 중 무작위 3문항, 부분곱 두 줄에서 각각 한 칸.
- 上: 10문제 중 무작위 5문항, 부분곱 두 줄과 최종 답에서 각각 한 칸.
- 下·5문제는 기존 순서 입력. 기존 올림 비중과 중복 없는 출제 유지.
- 완성된 숫자·계산선을 처음부터 표시하고 미완성 빈칸을 직접 선택 가능. 이미 맞힌 칸 재제출·중복 점수 금지.
- 문제당 200점·오답 −30점·문제당 시간 감점 최대 4점 유지. 칸을 오갈 때 각 칸의 활성 시간만 누적.
- 학생 화면에 난이도·설명 패널 없음. 곱셈 기호는 일반 숫자 색상.
- `questions.holes`를 서버에 저장하고 응답의 `puzzles:true`로 새 모드 확인. 이전 API 응답은 기존 문항으로 호환.

## 실제 브라우저

`tests/vertical-puzzle-preview.html`은 운영과 같은 `VerticalPlay`, `VerticalProgress`, `useVerticalGame`을 사용한다. 가상 학생 999의 로컬 저장소만 사용하고 운영 서버에 기록을 보내지 않는다. 테스트 선택 버튼은 실제 학생 화면에 포함되지 않는다.

- 中 1280×720: 32×12 완성 식에서 빈칸 두 개가 동시에 보임. 두 번째 칸부터 선택, 오답 1은 해당 칸 유지, 다른 칸 정답 후 이전 칸 복귀. 점수 70 → 168, 정답 모션 후 자동 전환 확인.
- 시간 기록: 두 번째 칸 오답 691ms, 첫 번째 칸 정답 1,047ms, 두 번째 칸 정답 65,339ms. 다른 칸에 머문 시간이 첫 번째 칸에 합산되지 않고 오답 칸의 재시도 시간은 누적됨.
- 上 390×720: 47×21 식에 빈칸 세 개, 주어진 부분곱·최종 답 숫자가 처음부터 표시. 마지막 답 칸을 먼저 키보드 8+Enter로 입력해 점수 66, 남은 두 칸 유지.
- 上 전체 10문제 완주: 빈칸 문항 5개, 정답 84칸, 1,999점, `10문제 완료` 표시. 빈칸은 역순 선택, 일반 문항은 기존 계산 순서로 입력.
- 中 전체 10문제 완주 (320×568): 빈칸 문항 3개, 정답 99칸, 1,999점, `10문제 완료` 표시. 자동 전환·완료 확인. 자동화 마지막 대기의 선택자가 완료 UI를 놓쳐 timeout을 반환했으나 즉시 DOM을 확인해 실제 완료 상태를 검증했다.
- 320×568에서 최소 44px 빈칸 버튼이 짧은 결과 행을 넘는 현상을 발견하고, 빈칸 문항의 불필요한 올림 행 여백을 줄여 결과 행을 50.4px로 확보. 버튼이 행 안에 들어오고 가로 넘침 없음.
- 上 390×720에서 모든 빈칸 터치 크기 44px 이상, 가로 넘침 없음, 곱셈 기호 rgb(28,22,56).
- 검증용 진입점의 HMR 중 createRoot 중복 경고는 dispose에서 root.unmount로 수정. 실제 제품 코드의 오류가 아님.
