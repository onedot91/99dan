# 교사 화면 오늘 플레이 표시

오늘 플레이한 학생은 기존 mint 토큰의 초록색 카드, 선택한 학생은 yellow 테두리로 구분한다. 문구·배지·장식 점은 추가하지 않는다. 스크린 리더용 aria-label에는 오늘 플레이 여부를 유지한다.

현재 운영 API가 제공하는 최근 구구단 세션의 finishedAt을 Asia/Seoul 날짜로 판별한다. answered > 0인 완료·중도 종료 기록만 포함한다. 진행 중인 게임과 미배포 두 자리수 곱셈 점수 테이블의 기록은 포함하지 않는다. 운영 변경이나 마이그레이션은 실행하지 않았다.

가상 데이터와 실제 Edge handler를 연결한 별도 localhost:5174 / :5175 환경에서 IAB로 교사 로그인 후 검증했다. 실제 학생 정보나 운영 교사 번호는 사용하지 않았다.

- 학생 1·3·6: 오늘 답한 기록, 모두 초록색. 3번은 오답만 있고 중도 종료했어도 참여로 표시.
- 학생 2: 어제 기록, 보라색. 선택하면 노란 테두리만 추가되고 초록색 학생은 유지.
- 학생 4: 기록 없음, 보라색.
- 학생 5: 오늘 종료했지만 답한 문제 0개, 보라색.
- 학생 7: 날짜 없음, 보라색.
- 모든 카드에 오늘 문구 없음. 접근성 이름에만 오늘 플레이 포함.
- 1280×720: 23개 카드, 높이 64px, 가로 넘침 없음.
- 320×568: 카드 60×64px, 4열, 가로 넘침 없음. 전체 페이지 스크린샷으로 텍스트 겹침 없음 확인.
- 한국 시간 자정 경계, 날짜 없음·잘못된 날짜·답안 없음, 날짜 전환 단위 테스트 3개 통과.
- 기존 곱셈 및 API 테스트 포함 16개 통과. npm run build 및 git diff --check 통과.
