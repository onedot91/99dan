# 두 자리수 곱셈 무작위 5문제

2026-10-02. 이전 고정 문항 구성을 새 연습마다 무작위 생성으로 대체한다. 쉬움/보통/어려움의 올림 없음·곱셈 올림·덧셈 올림 비중은 2/2/1, 1/2/2, 0/1/4를 유지하고 한 세트 안에서 같은 문항을 중복하지 않는다. 교사 화면에서 고정 5문항 미리보기를 제거했다. 학생에게 난이도 이름을 표시하지 않는다.

서버 시작 RPC가 무작위 문항을 생성·저장해 questions로 반환한다. 클라이언트는 번호·ID·5문항·범위·올림 비중·중복 여부를 확인한 후 그 문항으로 연습을 시작한다. 예비/오프라인 모드도 같은 비중으로 랜덤 생성한다. version 4는 받은 문항과 모든 입력을 저장하고 복원 시 같은 문항으로 재생한다. version 1·2·3도 기존 문제 그대로 복원한다. 고정 문항 상수는 이전 version 2/3 검증에만 사용한다.

## 검증

- 단위/API 테스트 18개 통과: 무작위 변화, 5문항 중복 없음, 세 가지 비중, 저장/재생, 기존 version 1·2·3 복원, 오답·점수·서명 세션, 클라이언트가 보낸 문항/난이도를 시작 RPC에 전달하지 않음.
- npm run build, git diff --check 통과.
- PostgreSQL 17.11 격리 DB 99dan_vertical_score_20261002_random에 최신 SQL 적용. 8,100개 곱셈의 칸 순서와 올림 분류가 프론트와 일치. 난이도별 20세트 생성해 모든 비중·중복 없음 및 서로 다른 세트 확인. 시작 응답의 문항으로 실제 프론트 입력 이벤트를 생성해 1000/940/0/970점 채점 확인. 같은 ID 재시도와 교사 설정 변경 후에도 문항 보존. 통합 순위·만료·초기화·역할 권한 검증 통과.
- 첫 SQL 테스트는 시작 응답에 새로 포함된 ID 때문에 시작 응답도 점수 응답으로 잘못 판별했다. score가 있는 완료 응답만 검증하도록 수정하고 재실행해 통과했다. 채점 기준은 변경하지 않았다.
- native IAB + 실제 Edge handler + 격리 DB로 화면 검증. 첫 시작 60×22, 첫 칸 0 입력 후 새로고침/이어서 풀기에서 같은 문제와 십의 자리 입력 위치 복원.
- 새 연습은 13×20, 78×10, 76×50, 47×85, 84×16으로 변경. 실제 5문제 완료 후 1000점 및 순위 저장 완료 확인. 다음 새 연습 첫 문제는 31×87로 변경.
- 모바일 320×568 풀이·완료 화면 확인. 교사 화면은 모바일 가로폭/scrollWidth 320, 고정 문항 목록 0개, 난이도와 비중 및 저장 버튼 유지. 데스크톱 1280×720 확인.
- 화면 증거 /private/tmp/99dan-random-evidence/의 play-320.png, result-320.png, teacher-320.png, teacher-1280.png.

가상 학생과 가짜 교사 번호만 사용했다. 새 점수 테이블/랜덤 시작 RPC의 운영 반영은 여전히 승인 대기이며 실제 서버 데이터는 변경하지 않았다. 추가 의존성·커밋·푸시 없음. 실제 학교 기기·보조기술은 미검증.
