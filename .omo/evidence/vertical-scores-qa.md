# 두 자리수 곱셈 점수·명예의 전당 검증

2026-10-02. 이번 변경은 홈/설정/교사 화면의 이름, 문제 완성 점수, 난이도별 명예의 전당, 별도 서버 저장이다. 기존 구구단 점수·펫 경험치는 유지한다.

## 동작
- 한 문제의 모든 칸 완료 +200점, 오답 입력마다 -30점, 합계 하한 0점. 첫 문제의 오답도 이후 획득 점수에서 차감한다. 5문제 만점 1,000점, 시간·속도·연속 정답 보너스 없음.
- 기존 30점 감점 상수를 공유한다. 칸 정답만으로 가점하지 않는다.
- 서버 시작 RPC가 교사 난이도/5문항을 고정한다. 서버 완료 RPC가 전체 입력 순서를 재생해 5문제 완료 여부와 오답을 확인한다. 전달한 score/studentNumber를 신뢰하지 않는다.
- version 3 UUID/전체 입력 이력 저장. 이전 version 1·2는 이어 풀 수 있고 순위 등록은 소급하지 않는다.
- 순위는 구구단/두 자리수 곱셈 전환, 곱셈 난이도별 최근 7일 최고 완료 점수 상위 5명. 동점은 먼저 달성한 기록, 이후 번호 순. 완료 화면에서 해당 난이도 탭을 연다.
- 저장 실패 시 기존 완료 기록과 점수를 보존하고 재시도를 제공한다. 저장 전 새 세트를 시작하지 않도록 막는다. 저장 재시도는 서버 UUID/해시로 중복 점수를 만들지 않는다.
- 교사 초기화는 완료된 곱셈 점수를 삭제하며 진행 중 세트와 난이도 설정은 유지한다. 운영 기록 초기화는 실행하지 않았다.
