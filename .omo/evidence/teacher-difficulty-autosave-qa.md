# 교사 난이도 자동 저장 확인

- 2026-10-02: 로컬 IAB, 가상 학생 23명과 로컬 Edge Function fixture 사용. 운영 데이터 변경 없음.
- 선택창, 학생 배지, 툴팁/접근성 이름의 난이도는 下 · 中 · 上으로 통일.
- 설정 패널에서 5문제 문구, 올림 비중 설명, 난이도 저장 버튼, 상시 저장 완료 문구 제거.
- 1번 下 → 上 변경만으로 저장. 요청 중 선택창 비활성화 및 저장 중 상태 표시, 완료 후 상태 문구 제거와 배지 갱신 확인.
- 2번 中 → 上 요청을 fixture에서 실패시켜 中 복원과 짧은 오류 표시 확인. 같은 上 재선택 시 저장 성공 및 오류 제거 확인.
- 기록 새로고침 후 저장된 上 유지 확인.
- 2번 下 저장 중 3번으로 이동 후 다시 2번 선택: 2번 下 유지, 3번 上 유지 확인.
- 1280×720 데스크톱, 320×568 모바일 화면 확인. 모바일 문서 너비 320px, 선택창 높이 44px, 가로 넘침 없음.
