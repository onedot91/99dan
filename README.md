# 구구단 게임

초등학교 3학년을 위한 구구단 회상 연습 웹앱입니다. 곱 맞히기, 빈칸 인수 맞히기, 두 곱 비교를 제공합니다.

## 실행

```sh
npm install
npm run dev -- --host 0.0.0.0
```

기본 주소: http://localhost:5173/

```sh
npm run build
npm run preview
```

React 19, TypeScript, Vite, CSS와 Supabase School_Timer를 사용합니다. 첫 접속 때 1~23번 중 자신의 번호를 선택하고 확인창에서 확정합니다. 번호는 같은 브라우저의 localStorage에 저장합니다. 동물 프로필은 School_Timer에서 읽고, 학습 기록과 최고 점수는 번호별로 서버에 저장해 다른 기기에서도 공유합니다. 연결 설정은 `supabase/README.md`를 참고하세요.

## 연습 방식

- **1·2·3분 도전:** 2~9단의 64개 곱셈식. 선택한 시간의 실제 경과시간으로 자동 종료합니다.
- **단별 연습:** 여러 단을 선택해 시간 제한 없이, 고른 각 단의 8개 식을 모두 풉니다.
- **약점 연습:** 최근 5회 응답에서 오답이 있는 문제를 중심으로 연습합니다. 연속 3회 정답이면 집중 목록에서 제외합니다.
- **입력:** 화면 숫자 패드, 실제 숫자 키, Enter, Backspace, Delete. Escape는 현재까지의 결과로 종료합니다.
- **문제 유형:** `a × b = □`, `□ × b = 결과`, `a × □ = 결과`, `a × b □ c × d`를 순환합니다. 비교 문제는 화면의 `<`, `=`, `>` 버튼이나 키보드로 답합니다.
- **피드백:** 정답 450ms 후 다음 식으로 진행합니다. 오답은 정답을 공개하지 않으며 350ms 후 같은 식을 다시 풉니다. 단별 연습은 오답 횟수와 관계없이 모든 식을 맞혀야 완료됩니다.
- **점수:** 정답 점수는 200점에서 시작해 100ms마다 1점씩 줄고 최소 100점입니다. 두 번째 연속 정답부터 10점씩 더해지며 최대 +50점입니다. 오답은 최대 30점 감점이며 점수는 0점 밑으로 내려가지 않습니다. 오답이면 연속 정답 수가 초기화됩니다.

오답은 같은 식을 맞힐 때까지 재도전합니다. 이후 정답이면 재출제 간격이 6→8→10→12문제로 늘어납니다. 숙달 문제는 예약 재출제를 해제하고 일반 추첨의 가중치를 낮춥니다. 1분 도전과 단별 연습은 선택 범위의 모든 식을 한 번씩 출제한 뒤 일반 반복으로 넘어갑니다. 집중할 문제가 적거나 아직 복습 차례가 아니면, 같은 문제를 바로 반복하지 않도록 다른 문제를 사이에 넣습니다.

반응시간은 문제가 DOM에 반영된 시점부터 답 확정까지 측정합니다. 숫자 입력이나 타이머 갱신은 시작시각을 초기화하지 않습니다. 피드백 시간은 다음 문제의 반응시간에 포함하지 않습니다. 중간 종료한 도전도 개인 최고 기록과 명예의 전당에 포함하며, 연습 기록은 순위에 포함하지 않습니다. 명예의 전당은 1·2·3분별 상위 5명까지 표시하며, 기록은 등록 시점부터 7일 동안 순위에 남습니다. 같은 학생은 시간별 순위에 한 번만 오릅니다.

이전 점수 규칙의 도전 기록은 최근 기록에 남고, 최고 점수와 명예의 전당은 현재 점수 규칙으로 완료한 도전만 표시합니다. 시간이 적게 남아도 타이머의 색과 효과는 바뀌지 않습니다.

결과는 퍼센트 대신 맞힌 개수·다시 볼 문제 개수를 표시하고, 최근 기록은 “6문제 중 5개 정답”처럼 표시합니다.

번호 선택 화면에서 교사 번호를 입력하면 1~23번 중 학생을 선택해 정답·오답 합계, 시간별 최고 점수, 최근 도전 5개를 볼 수 있습니다. 학생별 기록을 지우거나 확인 문구를 입력해 모든 학생 기록을 초기화할 수 있습니다. 교사 번호는 서버에서 확인하며 브라우저에 저장하지 않습니다.

## 화면·효과음

16비트 레트로 픽셀아트 스타일입니다. 픽셀 글꼴(Galmuri11, OFL)을 앱에 포함해 외부 요청 없이 불러옵니다. 1280×650 크롬북을 기준으로 문제와 키패드를 나란히 배치하고, 휴대폰에서는 세로로 배치합니다. 13pt 이상 글자를 유지합니다.

상단 소리 버튼은 기본 OFF입니다. 켜면 칩튠 효과음이 나옵니다. 정답음은 연속 정답마다 도-레-미-파-솔로 올라가고, 5콤보마다 팡파르가 울립니다. 결과 화면에서는 신기록, 레벨 업, 완료 팡파르 중 하나가 나옵니다. 새로고침하거나 탭을 숨기면 다시 꺼집니다. 외부 오디오 파일 없이 Web Audio로 합성하며, 시스템의 동작 줄이기 설정을 지원합니다.

## 학습 동기

점수 규칙과 출제 방식은 그대로 두고, 꾸준함과 숙달을 보상합니다.

- **레벨·경험치:** 초반 레벨은 누적 정답 10·20·30·40개로 빠르게 오르고(Lv2~5), 그 뒤로는 50개마다 하나씩 오릅니다. 상한은 없고, 레벨이 오를 때마다 펫을 하나 고릅니다. 칭호는 레벨 구간 이름입니다(1 초보 모험가, 3 숫자 탐험가, 6 곱셈 전사, 10 룬의 기사, 15 숫자 마법사, 20 곱셈 영웅, 30 별의 수호자, 40 전설의 대마법사, 50 곱셈 제왕).
- **예비 번호:** 번호 선택 화면의 '예비'는 1~23번 외의 손님·체험용 번호입니다. 모든 펫(328마리)과 배경을 쓸 수 있고, 서버에 연결하지 않아 기록이 저장되지 않으며 명예의 전당과 교사 화면에도 나오지 않습니다.
- **펫 나무:** 레벨마다 펫을 한 마리 고릅니다(레벨 1에서 첫 펫). 슬라임·로봇·드래곤·짹짹이·고양이·유령·버섯·거북이 8종이 있습니다. 각각 속성(불꽃·물결·새싹·번개), 변신(날개·왕관·마법), 전설(별빛·달빛)로 진화해 모두 328명입니다. 매번 3가지 선택지(다른 펫의 진화 최대 2개와 새 종류 1개)가 나옵니다. 선택지는 학생 번호와 고른 횟수로 정해져 새로고침해도 바뀌지 않습니다. 단계가 오를수록 모습과 크기가 달라집니다(알에서 막 나온 아기 → 속성 → 변신 → 빛나는 전설). 기본 캐릭터는 없고, 첫 펫을 고른 뒤부터 고른 펫이 홈 화면에서 함께 걷습니다.
- **콤보 미터:** 연속 정답 보너스(+10~+50)를 5칸으로 보여 줍니다.
- **구구단 도감:** `내 기록`에서 64개 식을 익힌 식·연습 중·다시 볼 식으로 색칠해 보여 줍니다.
- **결과 화면:** 최고 기록 갱신이나 최고 기록까지 남은 점수, 새로 익힌 식, 얻은 경험치를 보여 줍니다.
- 오답은 정답을 공개하지 않고, 부드러운 소리와 짧은 흔들림으로만 알립니다.

오프라인 미리보기(서버에 기록을 저장하지 않음):

```sh
VITE_GUGUDAN_API_URL= VITE_SUPABASE_PUBLISHABLE_KEY= npx vite --port 5174
```

## 주요 파일

- `src/game/useRushGame.ts`: 입력, 반응시간, 타이머, 자동 진행, 세션 기록
- `src/game/learning.ts`: 문제 풀, 간격 반복, 적응형 추첨, 숙달 판단, 레벨
- `src/game/useRunRewards.ts`: 도전 시작 시점과 비교해 신기록·레벨 업·새로 익힌 식 계산
- `src/game/audio.ts`: 칩튠 효과음 합성
- `src/components/Sprite.tsx`: ASCII 맵 픽셀 스프라이트
- `src/game/friends.ts`, `src/components/FriendSprite.tsx`: 펫 나무 정의, 선택지 추첨, 부품 조합 스프라이트
- `src/game/useFriends.ts`: 펫 저장(서버 지원 시 서버, 아니면 이 브라우저)
- `src/components/`: 시작, 문제, 숫자 패드, 단 선택, 결과, 기록 화면
- `src/components/StudentNumberScreen.tsx`, `src/game/studentNumber.ts`: 최초 번호 선택·확인·기기 저장
- `src/game/audio.ts`, `useGameAudio.ts`: 사용자 활성화와 효과음 수명 관리
- `src/motion.css`: 정답·오답·콤보와 화면 전환 반응
- `src/cloud/`, `supabase/`: 번호별 공유 기록·프로필·서버 채점·명예의 전당
- `DESIGN.md`: 최신 기획의 UI·학습 규칙
- `QA.md`: 실제 검증 결과
