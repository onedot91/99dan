# 구구단 게임

초등학교 3학년을 위한 구구단 회상 연습 웹앱입니다. 곱 맞히기, 빈칸 인수 맞히기, 두 곱 비교를 제공합니다.

## 실행

```sh
npm install
npm run dev -- --host 0.0.0.0
```

기본 주소: http://localhost:5173/

```sh
npm run build
npm run preview
```

React 19, TypeScript, Vite, CSS와 Supabase School_Timer를 사용합니다. 첫 접속 때 1~23번 중 자신의 번호를 선택하고 확인창에서 확정합니다. 번호는 같은 브라우저의 localStorage에 저장합니다. 동물 프로필은 School_Timer에서 읽고, 학습 기록과 최고 점수는 번호별로 서버에 저장해 다른 기기에서도 공유합니다. 연결 설정은 `supabase/README.md`를 참고하세요.

## 연습 방식

- **1·3분 도전:** 2~9단의 64개 곱셈식. 2분 도전은 2026-10-13에 뺐습니다(이전 2분 기록은 서버에 남아 있음). 선택한 시간의 실제 경과시간으로 자동 종료합니다.
- **단별 연습:** 여러 단을 선택해 시간 제한 없이, 고른 각 단의 8개 식을 모두 풉니다.
- **약점 연습:** 최근 5회 응답에서 오답이 있는 문제를 중심으로 연습합니다. 연속 3회 정답이면 집중 목록에서 제외합니다.
- **두 자리수 곱셈:** 시간 제한 없이 5문제를 완성합니다. 교사가 학생별로 下·中·上 세트를 지정합니다(기본 下). 올림 없음/곱셈 올림만/덧셈 올림 포함의 비중은 각각 2/2/1, 1/2/2, 0/1/4이며 새 연습마다 중복 없이 무작위로 뽑습니다. 학생 화면에는 난이도 표시가 없습니다. 현재 네모칸을 순차적으로 공개하고, 올림은 위의 작은 칸에 입력하며, 오답이면 해당 칸만 다시 풉니다. 정답 확인한 칸마다 문제당 200점을 나눠 받고, 오답 입력마다 30점을 감점합니다. 빈칸이 열린 순간부터 정답 확인까지 시간을 재며 오답 재시도도 포함합니다. 자동 입력 0과 문제 전환 모션은 시간 계산에서 제외합니다. 칸별 시간을 최대 20초까지 반영해 문제별 평균 5초마다 1점, 문제당 최대 4점을 감점합니다(서버 적용 대기). 정확히 풀면 느려도 최소 980점이며 시간 제한은 없습니다. 명예의 전당은 모든 난이도를 합친 학생별 최근 7일 최고 완료 기록 상위 5명입니다. 서버가 문항과 입력 순서를 검증해 재채점합니다. 나가거나 새로고침하면 진행은 끝나며 이어서 풀기는 없습니다. 완료 기록만 저장 재시도를 위해 브라우저에 보관합니다. 설정 변경은 다음 새 연습부터 적용합니다. 구구단 기록(오답 통계 등)에는 합산하지 않지만, 레벨 경험치에는 끝낸 문제당 10(구구단 정답은 1, 2026-10-13 이전에 시작한 판은 20)을 더하며 펫 한도에도 반영됩니다(`migrations/20261012000000_vertical_exp.sql`, `migrations/20261013000000_halve_run_exp.sql`). 서버 적용은 `supabase/README.md`를 참고하세요.
- **계단 (2026-10-26, 시범 운영):** 무한의 계단을 본뜬 종목입니다. 모든 번호의 홈·명예의 전당·내 기록에서 이용할 수 있습니다. 홈에서 두 자리 수 5·10문제 대신 계단을 선택합니다. 왼쪽 계단에서 「오르기」(보는 방향으로 한 칸, → 또는 X)와 「방향전환」(돌아서 한 칸, ← 또는 Z)으로 오르고, 7칸마다 나오는 문제 계단에서 오른쪽 세로셈 두 자리 곱셈 한 문제를 다 풀어야 다시 오릅니다. 목숨은 3개이며 방향 실수(그 자리에 그대로 섬)와 세로셈 찍기(같은 칸에서 1초 안에 또 틀리거나 같은 칸 세 번째 오답부터)에 하나씩 줄고, 그냥 틀린 답은 다시 풀면 됩니다. 문제는 푼 수에 따라 下(0~2문제) → 中(3~7) → 上(8~)으로 어려워지고, 0이 든 문제는 내지 않습니다. 일반 계단에는 무작위 코인이 놓이고, 도착하면 코인 1개당 50점을 얻습니다. 코인은 시작 칸과 문제 계단에는 나오지 않으며 같은 판에서는 위치가 고정됩니다. 점수는 오른 칸 × 10 + 푼 문제 × 200 + 모은 코인 × 50점이고, 경험치는 푼 문제당 10입니다. 블록처럼 서버가 시드로 판을 다시 돌려 점수를 저장하고 명예의 전당(최근 7일 최고 층수)에 올립니다. 휴대폰에서는 오를 때 계단, 풀 때 세로셈만 보입니다.
- **입력:** 화면 숫자 패드, 실제 숫자 키, Enter, Backspace, Delete. Escape는 현재까지의 결과로 종료합니다.
- **문제 유형:** `a × b = □`, `□ × b = 결과`, `a × □ = 결과`, `a × b □ c × d`를 순환합니다. 비교 문제는 화면의 `<`, `=`, `>` 버튼이나 키보드로 답합니다.
- **피드백:** 정답 450ms 후 다음 식으로 진행합니다. 오답은 정답을 공개하지 않으며 350ms 후 같은 식을 다시 풉니다. 단별 연습은 오답 횟수와 관계없이 모든 식을 맞혀야 완료됩니다.
- **점수:** 정답 점수는 200점에서 시작해 100ms마다 1점씩 줄고 최소 100점입니다. 두 번째 연속 정답부터 10점씩 더해지며 최대 +50점입니다. 오답은 최대 30점 감점이며 점수는 0점 밑으로 내려가지 않습니다. 오답이면 연속 정답 수가 초기화됩니다.

오답은 같은 식을 맞힐 때까지 재도전합니다. 이후 정답이면 재출제 간격이 6→8→10→12문제로 늘어납니다. 숙달 문제는 예약 재출제를 해제하고 일반 추첨의 가중치를 낮춥니다. 1분 도전과 단별 연습은 선택 범위의 모든 식을 한 번씩 출제한 뒤 일반 반복으로 넘어갑니다. 집중할 문제가 적거나 아직 복습 차례가 아니면, 같은 문제를 바로 반복하지 않도록 다른 문제를 사이에 넣습니다.

반응시간은 문제가 DOM에 반영된 시점부터 답 확정까지 측정합니다. 숫자 입력이나 타이머 갱신은 시작시각을 초기화하지 않습니다. 피드백 시간은 다음 문제의 반응시간에 포함하지 않습니다. 중간 종료한 도전도 개인 최고 기록과 명예의 전당에 포함하며, 연습 기록은 순위에 포함하지 않습니다. 명예의 전당은 1·2·3분별 상위 5명까지 표시하며, 기록은 등록 시점부터 7일 동안 순위에 남습니다. 같은 학생은 시간별 순위에 한 번만 오릅니다.

이전 점수 규칙의 도전 기록은 최근 기록에 남고, 최고 점수와 명예의 전당은 현재 점수 규칙으로 완료한 도전만 표시합니다. 시간이 적게 남아도 타이머의 색과 효과는 바뀌지 않습니다.

결과는 퍼센트 대신 맞힌 개수·다시 볼 문제 개수를 표시하고, 최근 기록은 “6문제 중 5개 정답”처럼 표시합니다.

번호 선택 화면에서 교사 번호를 입력하면 1~23번 중 학생을 선택해 정답·오답 합계, 시간별 최고 점수, 최근 도전 5개(구구단 도전·연습과 두 자리 수 5문제·10문제를 날짜순으로 함께 표시, 두 자리 수는 오답 개수와 점수)를 볼 수 있습니다. 학생별 기록을 지우거나 확인 문구를 입력해 모든 학생 기록을 초기화할 수 있습니다. 교사 번호는 서버에서 확인하며 브라우저에 저장하지 않습니다.

한국 시간 기준 오늘 저장된 구구단 플레이 기록이 있는 학생은 초록색 카드로 표시하고, 선택한 학생은 노란 테두리로 구분합니다. 한 문제 이상 답한 완료·중도 종료 기록 기준이며 진행 중인 게임, 답하지 않은 게임, 날짜가 없는 기록은 포함하지 않습니다. 날짜는 1분마다 또는 화면 복귀 시 다시 판별하고, 새 플레이 기록은 교사 화면의 새로고침으로 불러옵니다.

## 화면·효과음

16비트 레트로 픽셀아트 스타일입니다. 픽셀 글꼴(Galmuri11, OFL)을 앱에 포함해 외부 요청 없이 불러옵니다. 1280×650 크롬북을 기준으로 문제와 키패드를 나란히 배치하고, 휴대폰에서는 세로로 배치합니다. 13pt 이상 글자를 유지합니다.

상단 소리 버튼은 기본 OFF입니다. 켜면 칩튠 효과음이 나옵니다. 정답음은 연속 정답마다 도-레-미-파-솔로 올라가고, 5콤보마다 팡파르가 울립니다. 결과 화면에서는 신기록, 레벨 업, 완료 팡파르 중 하나가 나옵니다. 새로고침하거나 탭을 숨기면 다시 꺼집니다. 외부 오디오 파일 없이 Web Audio로 합성하며, 시스템의 동작 줄이기 설정을 지원합니다.

## 학습 동기

점수 규칙과 출제 방식은 그대로 두고, 꾸준함과 숙달을 보상합니다.

- **레벨·경험치:** 초반 레벨은 누적 정답 10·20·30·40개로 빠르게 오르고(Lv2~5), 그 뒤로는 50개마다 하나씩 오릅니다. 상한은 없고, 레벨이 오를 때마다 펫을 하나 고릅니다. 칭호는 레벨 구간 이름입니다(1 초보 모험가, 3 숫자 탐험가, 6 곱셈 전사, 10 룬의 기사, 15 숫자 마법사, 20 곱셈 영웅, 30 별의 수호자, 40 전설의 대마법사, 50 곱셈 제왕, 60 곱셈 황제, 70 은하 정복자, 80 우주의 수호신, 90 불멸의 전설, 100 곱셈의 신, 110 차원의 여행자, 120 시간의 마법사, 130 은하의 현자, 140 별을 빚는 자, 150 무한의 탐구자, 160 숫자의 창조주, 170 영원의 수호자, 180 천상의 지배자, 190 전설을 넘은 자, 200 곱셈 초월자). 배경도 레벨에 따라 열립니다: Lv30 우주 이후 35 반딧불, 42 보석, 50 황금, 60 사탕, 72 무지개, 85 폭풍, 100 천상, 110 심해, 125 네온, 140 구름섬, 155 성운, 175 시간, 200 블랙홀(뒤로 갈수록 간격이 벌어짐).
- **예비 번호:** 번호 선택 화면의 '예비'는 1~23번 외의 손님·체험용 번호입니다. 모든 펫(1424마리)과 배경을 쓸 수 있고, 서버에 연결하지 않아 기록이 저장되지 않으며 명예의 전당과 교사 화면에도 나오지 않습니다.
- **펫 나무:** 레벨마다 펫을 한 마리 고릅니다(레벨 1에서 첫 펫). 슬라임·로봇·드래곤·짹짹이·고양이·유령·버섯·거북이·곰·문어·유니콘·펭귄 12종과 Lv100부터 만날 수 있는 토끼·고래·외계인·별똥이 4종, 모두 16종이 있습니다. 각각 속성(불꽃·물결·새싹·번개), 변신(날개·왕관·마법), 전설(별빛·달빛), 신화(천사·우주)로 진화해 16 × (1 + 4 + 12 + 24 + 48) = 모두 1424명입니다. 매번 3가지 선택지(다른 펫의 진화 최대 2개와 새 종류 1개)가 나옵니다. 선택지는 학생 번호와 고른 횟수로 정해져 새로고침해도 바뀌지 않습니다. 단계가 오를수록 모습과 크기가 달라집니다(알에서 막 나온 아기 → 속성 → 변신 → 빛나는 전설 → 천사 고리·날개나 행성 고리를 두른 신화). 기본 캐릭터는 없고, 첫 펫을 고른 뒤부터 고른 펫이 홈 화면에서 함께 걷습니다.
- **콤보 미터:** 연속 정답 보너스(+10~+50)를 5칸으로 보여 줍니다.
- **내 기록:** 1·3분 도전은 최고 점수와 정답 수, 계단·블록 탭은 최고 점수(서버와 이 기기 중 높은 값)와 끝낸 판 수를 보여 줍니다(두 자리 수 5·10문제 탭과 함께 계단). 블록 탭은 최고 점수(서버와 이 기기 중 높은 값)와 끝낸 판 수를 보여 줍니다.
- **구구단 도감:** `내 기록`에서 64개 식을 익힌 식·연습 중·다시 볼 식으로 색칠해 보여 줍니다.
- **결과 화면:** 최고 기록 갱신이나 최고 기록까지 남은 점수, 새로 익힌 식, 얻은 경험치를 보여 줍니다.
- 오답은 정답을 공개하지 않고, 부드러운 소리와 짧은 흔들림으로만 알립니다.

## 주요 파일

- `src/game/useRushGame.ts`: 입력, 반응시간, 타이머, 자동 진행, 세션 기록
- `src/game/vertical.ts`, `useVerticalGame.ts`: 세로셈 출제·올림·단계별 채점·진행 저장
- `src/components/VerticalScreen.tsx`, `src/vertical.css`: 세로셈 난이도·풀이·완료 화면
- `src/game/learning.ts`: 문제 풀, 간격 반복, 적응형 추첨, 숙달 판단, 레벨
- `src/game/useRunRewards.ts`: 도전 시작 시점과 비교해 신기록·레벨 업·새로 익힌 식 계산
- `src/game/audio.ts`: 칩튠 효과음 합성
- `src/components/Sprite.tsx`: ASCII 맵 픽셀 스프라이트
- `src/game/friends.ts`, `src/components/FriendSprite.tsx`: 펫 나무 정의, 선택지 추첨, 부품 조합 스프라이트
- `src/game/useFriends.ts`: 펫 저장(서버 지원 시 서버, 아니면 이 브라우저)
- `src/components/`: 시작, 문제, 숫자 패드, 단 선택, 결과, 기록 화면
